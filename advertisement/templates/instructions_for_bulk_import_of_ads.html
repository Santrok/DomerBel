Пользователь доски объявлений Домер имеет возможность массово добавлять объявления. Обращаем внимание, что услага является платной. Массовый импорт объявлений можность осуществить при помощи:
- XLSX- файла;
- ZIP- архива, содержащено XLSX- файл и изображение для объявлений.

Требование к полям для объявлений:

  • Артикул:
    1. - Является необязательным для заполнения полем;
    2. - Не должен превышать 255 символов;
    3. - Должен быть уникальным для всех объявлений загруженных одним пользователем.
  • Заголовок:
    1. - Является обязательным для заполнения;
    2. - Не должен превышать 255 символов;
    3. - Не должен содержать только цифры.
  • Цена:
    1. - Является не обязательным для заполнения;
    2. - Числовое значение, разделяемое точкой дробную и челую часть числа;
    3. - Цена указывается в белорусских рублях.
  • Категория:
    1. - Является обязательным для заполнения;
    2. - Значение поля берется из установленного списка.
  • Регион:
    1. - Является обязательным для заполнения;
    2. - Значение поля берется из установленного списка.
  • Описание:
    1. - Является обязательным для заполнения.
  • Фото:
    1. - Является необязательным для заполнения полем;
    2. - В поле в XLSX- файле указывается полное название файла с расширением;
    3. - Не более 30 изображений для одного объявления.

Импорт бъвлений и изображений с локального компьютера:

Шаг 1: заполните XLSX- файл в соответствии с требованиями указанными выше

Шаг 2: Создайте ZIP-архив, который будет содержать XLSX-файл и все изображения, которые вы указали в XLSX-файле.

Шаг 3: Файл готов к загрузки.

Импорт объявлений:

  • 1. Перейдите в личный кабинет.
  • 2. Нажмите кнопку “Массовый импорт”.
  • 3. Нажмите кнопку"Выбрать файл". Выберите файл на локальном компьютере (XLSX- файл, ZIP-архив), подготовленный вами ранее для подачи объявлений.
  • 4. Нажмите кнопку “Отправить”.
  • 5. Файл начнет обрабатываться. Время обработки файла зависит от количества подаваемых объявлений и изображений.
  • 6. По факту завершения обработки файла вы получите информацию о результате импорта объявлений.
  • 7. Если в объявление будет некорректно заполнено одно из полей, вам будет предложено скачать XLSX-файл, содержащий объявления с ошибками.
  • 8. Исправьте найденные ошибки и заново загрузите файл. При загрузке ZIP-архива необходимо заново создавать архив откорректированным XLSX-файл и изображениями.
